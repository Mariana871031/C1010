# C1010
Introducción a la programación científica de la Maestría de Bioinformática UNIR México




Cada integrante del equipo configuró su usuario y correo utilizando los siguientes cmomandos

```
git config --global user.name "Nombre completo"
git config --global user.email "Correo"
```
Esto con el fin de poder identificar al autor de cada `commit`

Para revisar que la configuración de los usuarios es correcta se puede utilizar `git config --global --list`
